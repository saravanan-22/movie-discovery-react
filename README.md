# 🎬 Movie App (React)

A movie & TV discovery app powered by **The Movie Database (TMDB) API**, with user accounts via **Firebase Authentication**.

**▶ Live demo: [aj-react-p2-movieapp.vercel.app](https://aj-react-p2-movieapp.vercel.app/)**

## Features
- 🔐 Register, log in, reset password and edit profile (Firebase Auth)
- 🔥 Browse **Trending**, **Movies**, **TV Series**, **Top Rated** and **Now Playing**
- 🔎 Search movies and TV shows
- 🏷️ Filter by genre, with pagination
- 🎞️ Details modal with cast carousel and YouTube trailer

## Tech stack
React · React Router · Material UI · React Bootstrap · Axios · Firebase Auth · TMDB API · Vercel

## Run locally
```bash
git clone https://github.com/saravanan-22/movie-app-react.git
cd movie-app-react
npm install
cp .env.example .env   # then add your TMDB API key
npm start
```
